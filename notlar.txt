Hafta 4 - Ogrendigim 5 Linux Komutu
1. pwd   : Bulundugum dizinin tam yolunu gosterir.
2. ls -la: Dizindeki gizli dosyalar dahil tum dosyalari ayrintili listeler.
3. cd    : Dizin degistirir (cd .. bir ust dizine cikar).
4. mkdir : Yeni klasor olusturur (mkdir -p ic ice klasor olusturur).
5. chmod : Dosya izinlerini degistirir (chmod 755 script.sh).

Hafta 2 - Ogrendigim 5 Git Komutu
1. git init   : Bulundugum klasoru yeni bir Git reposuna donusturur.
2. git status : Hangi dosyalarin degistigini, staged/untracked oldugunu gosterir.
3. git add    : Degisiklikleri staging area'ya (commit'e hazir alana) alir.
4. git commit : Staging'deki degisiklikleri mesajla birlikte kalici olarak kaydeder.
5. git log    : Commit gecmisini listeler (--oneline ile kisa bicimde).

Ek Git Komutlari
- git branch : Branch'leri listeler, aktif olan * ile gosterilir.
- git switch -c <ad> : Yeni branch olusturup ona gecer.
- git merge <branch> : Baska bir branch'i bulundugum branch'e birlestirir.
